# AWS SNS Token Debugging Guide

## Problem
AWS SNS requires device tokens to be no more than 400 hexadecimal characters, but sometimes the tokens generated by your app don't meet this requirement.

## Solution
This update adds comprehensive token validation and formatting to ensure your push tokens are compatible with AWS SNS.

## What's Been Fixed

### 1. Token Validation and Formatting (`lib/awsSnsTokenUtils.ts`)
- **iOS APNs tokens**: Validates 64 hexadecimal character requirement
- **Android FCM tokens**: Ensures valid characters and length limits
- **AWS SNS compliance**: Enforces 400-character limit
- **Automatic cleaning**: Removes spaces, dashes, and invalid characters

### 2. Enhanced Push Notifications (`lib/pushNotifications.ts`)
- **Comprehensive validation**: Uses new validation utilities
- **Better logging**: Shows original vs formatted token lengths
- **Debug function**: `debugPushTokenSetup()` for complete diagnosis
- **Error handling**: Graceful handling of invalid tokens

### 3. Debug Component (`components/token-debug-screen.tsx`)
- **Visual debugging**: UI component to test token generation
- **Step-by-step testing**: Individual test buttons for each step
- **Real-time results**: Shows validation results and warnings

## What the Debug Shows

### ✅ Success Indicators
- **Token Valid**: Token passes all AWS SNS requirements
- **Correct Length**: 64 chars for iOS, ≤400 for Android  
- **Clean Format**: No invalid characters
- **Registration Success**: Backend accepted the token

### ⚠️ Warning Indicators
- **Format Changes**: Spaces or dashes were removed
- **Length Issues**: Token length unexpected but fixable
- **Character Cleanup**: Invalid characters were filtered out

### ❌ Error Indicators
- **Too Long**: Token exceeds 400 character AWS SNS limit
- **Invalid Format**: Token couldn't be fixed automatically
- **Permission Issues**: Notifications not permitted
- **Registration Failed**: Backend rejected the token

## Common Issues and Solutions

### Issue: "Token exceeds AWS SNS limit"
**Solution**: The new formatter automatically truncates to 400 chars

### Issue: "iOS token unexpected length"
**Solution**: Formatter cleans the token to exactly 64 hex chars

### Issue: "Token contains invalid characters"
**Solution**: Formatter removes spaces, dashes, and non-hex chars

### Issue: "Registration failed"
**Possible causes**:
1. Backend server configuration
2. AWS SNS endpoint setup
3. Platform application settings
4. AWS credentials/permissions

## Backend Considerations

Your backend should now receive:
- **pushToken**: Properly formatted token (≤400 chars)
- **platform**: 'ios' or 'android'  
- **tokenLength**: Length of formatted token
- **originalTokenLength**: Length before formatting

Make sure your backend AWS SNS integration uses the formatted `pushToken` value.
